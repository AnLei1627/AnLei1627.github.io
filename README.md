# Tutoring Availability · 家教可上課時段

中英雙語的家教空檔頁，訪客打開時自動換算成**他自己的時區**。學生點時段 → 輸入名字 → 送出預約。

- 網頁：純靜態 `index.html` + `availability.json`，GitHub Pages 直接跑
- 預約後端：`apps-script/Code.gs`（Google 試算表 + Apps Script），預約寫進試算表並寄信通知

## 一、更新開放時段

只改 `availability.json`：

```json
{
  "updated": "2026-11-03",
  "timezone": "America/New_York",
  "notice": { "zh": "…", "en": "…" },
  "slots": [
    { "date": "2026-11-04", "start": "06:00", "end": "09:00" },
    { "date": "2026-11-10", "start": "19:00", "end": "21:00", "tz": "Asia/Taipei" }
  ]
}
```

- `timezone`：時段用**哪個時區的時間**寫（寫你當下所在地即可）；單筆可用 `tz` 覆寫
- `end` 比 `start` 早 = 跨午夜
- 已過去、已被預約的時間會自動從網頁上扣掉；剩不到 1 小時的零碎時段不顯示
- **不要寫學生名字或地點**，這是公開網頁

## 二、預約後端設定（一次性，約 5 分鐘）

1. 開一份新的 Google 試算表（名字隨意，例如「家教預約」）
2. 選單 **擴充功能 → Apps Script**，把 `apps-script/Code.gs` 整份貼上、存檔
3. 上方函式選單選 `setup` → **執行** → 依指示授權（會要求試算表、寄信、讀網址的權限）
4. 右上 **部署 → 新增部署作業** → 類型選「**網頁應用程式**」
   - 執行身分：**我**
   - 誰可以存取：**所有人**
5. 複製部署後的網址（`https://script.google.com/macros/s/…/exec`），貼到 `index.html` 的 `BOOKING_URL`

之後改了 `Code.gs` 要重新部署時，用「**管理部署作業 → 編輯 → 新版本**」，網址才不會變。

## 三、日常

- 有人預約 → 你會收到 email，試算表「預約」工作表多一列，狀態是「待確認」
- **取消**：把那列的「狀態」改成「取消」，那段時間就會重新開放
- 學生的名字只存在試算表，網頁只會拿到「哪些時間被訂走」
